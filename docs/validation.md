## 시각·저장 검증

동일 입력의 공통 기본 표상, 8/10FPS에서 동일한 잔상 시간, 입력 종료 후 완전 소멸,
Sleep 이동 잔상 없음, std 효과의 평균 불변/국소성, 마이크 위상 상쇄 방지,
위치별 시간 균등 평균, 재시작 중복 방지, schema 추가 시 기존 통계 보존을 테스트한다.

실제 발화 표시 모드가 발화하지 않은 픽셀을 추가로 켜지 않는지 확인한다.
느린 방사형 효과는 burst가 없을 때 시작되지 않고 파동 시계가 0.30배로 진행한다.
이 검증은 렌더러 동작에 관한 것이며 임계성의 통계적 입증이 아니다.
