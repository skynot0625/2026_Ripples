# SNN·criticality·Sleep: 과학과 작품의 연결

2026-11-25 현장 구현을 기준으로, 연구에서 알려진 내용과 이 작품이 실제로 하는 일을 구분합니다. 관람자용 짧은 답은 [전시 해설](EXHIBITION_GUIDE.md)에 있습니다.

## 1. 현재 모델에서 계산하는 것

[reservoir 설정](../src/ripples/reservoir.py)은 B0 adaptive LIF 흥분성/억제성 재귀 신경망을 8,460개로 구성합니다. 흥분성 6,768개, 억제성 1,692개이며, 확장할 때 연결 확률을 조정해 뉴런당 기대 입력 연결 수를 유지합니다. 이 조정만으로 원래 모델과 임계점이 같다는 결론은 나오지 않습니다.

뉴런은 입력을 누적하고 누설시키며, 역치를 넘으면 spike를 낸 뒤 리셋·불응기를 거칩니다. 적응 변수는 최근 발화가 다음 활동에 영향을 주게 합니다. 흥분성 연결은 활동을 전달하고 억제성 연결은 이를 억제합니다. 잡음 구동도 포함합니다. 수학적 세부는 [adaptive LIF](../src/snnrc/neurons/adaptive_lif.py), [E/I reservoir](../src/snnrc/reservoir/biological_ei.py), [preset](../src/snnrc/presets.py)에 있습니다.

| 항목 | 현장 값 / 의미 |
|---|---|
| 뉴런 수 | 8,460 |
| 모델 | B0, 한 계산 스텝 뒤 재귀 전달 |
| 가중치 배율 | gain 9.5 |
| 적분 간격 | dt=0.1ms |
| 표시 한 프레임 | 모델 40스텝=4ms를 묶음 |
| LED 송신 | 목표 10FPS, 현장 약 8.2FPS 관측 |
| 표시 후처리 | 1.5초 발화 잔광, Active 발화 밝기 12%, 공간 층 분리, 밝기 제한 |
| 센서와 SNN의 관계 | 별도 계산한 센서 표상과 SNN 활동을 마지막 화면에서 합성 |
| 현재 학습 | 공간 통계 갱신. 전시 경로에는 학습된 readout·센서 기반 가중치 업데이트 없음 |

SNN은 신호를 spike라는 사건으로 주고받는 신경망 계열입니다. Reservoir computing에서는 재귀 동역학을 입력의 시간 정보를 펼치는 매질로 쓰고, 이를 읽는 출력기를 학습할 수 있습니다. [Maass·Natschläger·Markram, 2002](https://doi.org/10.1162/089976602760407955)는 이런 시간 의존 계산의 대표적 틀입니다. **현재 전시는 이 저장소에 포함된 reservoir의 자발 활동을 시각화하며, 학습된 과제 출력기를 운용하지 않습니다.** SNN이라는 구조를 사용했다는 사실과 AI 과제의 학습·성능 증명은 별개입니다.

## 2. 임계성이 흥미로운 이유와 판정의 한계

임계성은 집단의 동작 방식이 바뀌는 전이 부근의 성질입니다. 신경 활동의 전파를 단순화하면, 금방 소멸하는 쪽과 지속적으로 증폭되는 쪽 사이의 경계를 생각할 수 있습니다. 단순 분기 모형에서 한 사건이 다음 세대에 만드는 사건 수의 평균이 1 부근이라는 설명은 유용하지만, 유한하고 외부 구동이 있는 E/I 모델에 그대로 대입해 판정할 수는 없습니다.

Beggs와 Plenz는 배양·절편 피질의 활동 연쇄에서 neuronal avalanche 통계를 보고했습니다. 논문은 avalanche 상태를 단순한 oscillation·동기화·파동과 구분합니다. 그러므로 **탑 전체가 리듬 있게 밝아진다는 사실은 임계성의 증거와 같지 않습니다.** [Beggs & Plenz, 2003](https://pmc.ncbi.nlm.nih.gov/articles/PMC6741045/).

일부 흥분성 네트워크 모델에서는 임계점 부근에서 입력 세기의 넓은 범위를 구분하는 동적 범위가 커집니다. 이는 임계성에 관심을 갖는 계산적 동기입니다. 이 탑의 감각 분별 능력이나 에너지 효율이 최적이라는 실측 결과를 뜻하지는 않습니다. [Kinouchi & Copelli, 2006](https://arxiv.org/abs/q-bio/0601037).

뇌 전체가 언제나 정확한 임계점에 있다는 주장도 확정된 전제가 아닙니다. 외부 구동과 부분 관측을 고려했을 때 약간 아임계인 상태를 제안한 연구도 있습니다. [Priesemann et al., 2014](https://www.frontiersin.org/journals/systems-neuroscience/articles/10.3389/fnsys.2014.00108/full).

### 이 설치에서 확인한 것과 아직 확인하지 않은 것

| 구분 | 범위 |
|---|---|
| 코드로 확인 | 뉴런 수·E/I 구성·gain·dt·발화 계산, 두 상태의 표시 합성 |
| 동작 시험 | 렌더링, 통신·저장, 경로 압축·재시작, 상태 전환, 명도 제한 |
| 관찰 | 집단 발화와 LED 잔광이 만드는 시간적 패턴 |
| 아직 별도 검증 필요 | 최종 8,460 뉴런·gain9.5 조건의 임계성 판정, 유한 크기 스케일링, 계산 이득 |
| 주장하지 않음 | 인간 뇌의 완전한 복제, 의식·꿈의 경험, 수면으로 학습 성능이 향상됐다는 결론 |

전시 설명에는 **“임계성을 탐구하는 SNN 동역학의 시각화”**가 적절합니다. ‘정확한 임계점이 검증된 인공 뇌’라는 표현은 현재 근거를 넘습니다.

### 연구 검증을 이어간다면

원시 모델 spike 시각을 기록하고, 여러 seed와 gain 주변 조건을 비교합니다. Avalanche의 시작·끝과 시간 bin을 명시하고, 크기·지속시간 분포와 대안 분포를 비교하며, 분기 추정의 구동·샘플링 편향과 네트워크 크기 의존성을 검사합니다. 한 장의 log-log 직선이나 단일 지수만으로 판정하지 않습니다. 발화율·동기화·자기상관·PSD는 함께 볼 진단값이지만 각각 임계성의 충분조건은 아닙니다.

**LED 영상을 원시 spike처럼 분석하면 안 됩니다.** 4ms 모델 시간을 약 0.122초의 현장 화면 간격에 내보내므로 모델 시간은 약 30.5배 늘어나 보입니다(8.2FPS 관측 기준). 여기에 잔광과 제한된 표본화가 더해집니다. 화면의 느린 oscillation 주파수를 생물학적 뇌파 주파수로 읽을 수 없습니다.

## 3. 생물학적 수면과 작품의 Sleep

동물이 공간을 경험한 뒤 잠자는 동안, 경험과 연관된 해마 뉴런들의 활동 관계가 다시 나타나는 현상이 보고됐습니다. 이는 수면 중 기억 재활성화라는 연구 방향의 중요한 근거입니다. [Wilson & McNaughton, 1994](https://pubmed.ncbi.nlm.nih.gov/8036517/).

또 다른 실험에서는 학습 후 해마 sharp-wave ripple을 선택적으로 방해했을 때 공간 기억 수행이 저하됐습니다. 이는 해당 신경 활동과 기억 공고화 사이의 기능적 관계를 지지합니다. 여기서 ripple은 신경생리학적 활동 사건이며 LED의 방사형 물결 효과를 뜻하지 않습니다. [Girardeau et al., 2009](https://pubmed.ncbi.nlm.nih.gov/19749750/).

| 생물학 연구의 개념 | 작품에서 가져온 구성 | 동일하다고 주장하지 않는 부분 |
|---|---|---|
| 경험 관련 활동의 재활성화 | 기록된 경로를 순서대로 다시 드러냄 | 실제 해마 replay의 신경 코드를 구현한 것은 아님 |
| 경험의 장기 보존·변형 | 위치별 누적 평균과 변동을 유지 | 해마→피질 전송·가소성·기억 공고화 효과를 측정하지 않음 |
| 수면 중 내적 활동 | 외부의 현재 흔적 대신 기억과 SNN 활동을 관찰 | 실제 NREM/REM 단계나 의식의 상태 전이를 모사하지 않음 |
| 꿈이라는 작품 언어 | 서로 다른 시점의 감각이 아른거리며 나타남 | 기계의 주관적 경험을 확인한 것이 아님 |

생물학적 수면 전체를 단순한 파일 재생으로 환원해서도 안 되고, 작품의 재현을 생물학적 수면과 동일시해서도 안 됩니다. **이 작품의 연결은 과학에서 영감을 얻은 설계와 미학적 해석입니다.**

## 4. Sleep에서 실제로 일어나는 계산

1. Active·Sleep 모두 유효한 위치와 센서 특징을 수신합니다.
2. 24×24 공간 셀에서 같은 초의 특징을 평균한 뒤 Welford mean·M2·n을 갱신합니다. std는 개별 ADC 샘플이 아니라 **1초 평균들 사이의 표본 표준편차**입니다.
3. 기구별 초당 한 위치의 시간순 경로를 디스크에 보존합니다.
4. Sleep 시작 시 재생할 경로를 선택해 480초에 걸쳐 따라갑니다. 이 경로가 각 위치의 누적 평균·std를 드러내는 마스크가 됩니다. 과거 각 순간의 원본 특징 전체를 되감는 방식은 아닙니다.
5. 마지막 3초 동안 전체 기억으로 펼쳐져, 480–600초에는 관측된 모든 공간을 표시합니다.
6. 평균±std를 같은 감각 맵핑에 넣어 차이를 얻고, 시간상수 3.2초의 부드러운 국소 잡음으로 아른거림을 만듭니다. 두 번 이상 관측한 특징에 std를 적용합니다.
7. SNN 활동은 두 상태에서 계속되고, Sleep 경로를 시간 압축해도 신경망의 계산 속도를 그 비율로 가속하지 않습니다.

평균은 반복 관측의 중심이고 std는 변동의 크기입니다. std가 크다고 새로운 의미를 발견했다거나 통계적 확신이 낮다고 곧바로 해석하지 않습니다. 위치 오차, 센서 잡음, 실제 공간 변화가 모두 변동에 기여할 수 있습니다. 관측량과 결측을 함께 보아야 합니다.

## 5. 설명에 사용할 표현

| 사용할 수 있는 표현 | 피할 표현 |
|---|---|
| 뇌에서 영감을 받은 SNN 기반 작품 | 사람처럼 이해하고 의식적으로 꿈꾸는 AI |
| 임계성을 탐구하는 네트워크 활동 | 깜빡임으로 임계성이 입증된 인공 뇌 |
| 누적된 감각 통계와 경로의 재현 | 관객의 기억이나 감정을 읽어 저장 |
| 수면의 기억 재활성화 연구에서 영감을 받은 Sleep | 실제 수면과 같은 방식으로 학습·기억 공고화 완료 |
| 스펙트럼 중심 주파수에 따른 빛의 높이 | 음량만으로 알아낸 정확한 음정·발화 문장 |
