선택한 블라인드

master canvas에서 이 블라인드가 보여줄 영역 (실제 간격 포함한 위치)

실제 크기 (실측)

가로와 세로를 같은 단위로 입력 (cm·mm·m 무엇이든 — 비율만 씀). 비우면 실측 없음 = 지금 그대로. 모서리는 움직이지 않음.

부스 설정

간격

같은 저장값에서 화면 결과만 바뀜. 간격 포함은 블라인드 사이 빈 공간도 master canvas에 포함, 간격 무시는 영상을 블라인드끼리 바로 이어 붙임.

출력 내용

설치 당일 실제 치수로 바꾸는 값 (현재 값은 임시).

블라인드 모양은 그대로 두고 원본 시각화의 가로·세로를 같은 배율로 확대함. 비율은 유지되고 화면 밖 부분만 잘림. 테스트 패턴에는 적용되지 않음.
