누르는 동안 움직임. 키보드 W/S(↑/↓) 전진·후진, A/D(←/→) 회전, Q/E 옆으로. mock 시뮬레이션에서만 움직임.

탑 안의 가상 공간(차가운 흰색) = 혈 주변 ±6 m의 갤러리 M30을 0.16배로 줄인 모형. 혈을 따라가고 혈과 같이 돎(혈의 앞 = 탑의 A행 쪽, 보통 보는 사람의 반대쪽이라 혈 어깨 너머로 보는 느낌). 바닥은 탑 높이 1.0 m의 한 층(1 m 격자), 벽·기둥·가벽·유리·전시물은 공식 도면 형상(높이 0.6배, 2.6 m에서 잘라 위가 열린 모형), 지나다니는 사람 = 시뮬레이터 관람객, 가운데 깜빡이는 점 = 혈. 혈 ToF가 최근 약 90초 동안 본 바닥·벽은 더 밝아짐(쌓인 센서 기록, AI 학습 결과 아님). AI 학습 결과가 아니라 쌓인 센서 기록입니다. 따뜻한 흰색 = 맥(점)과 소리 : 맥 마이크 3개(가정 배치)의 레벨 차로 어림한 방향에서, 그 방향에 가장 가까운 관람객(±25°, 8 m 안)을 소리 나는 곳으로 추정해(없으면 그 방향 2.5 m 앞) 입 높이에서 구 모양 물결이 0.5초마다 퍼짐(밝기 = 소리 크기). 위치는 추정이고 마이크는 방향만 줌. 지금은 시뮬레이터 mock 데이터입니다.

공간 샘플은 3차원 부피 안의 모양을 LED로 찍어 본 예시입니다. AI가 학습한 공간을 보여 줄 콘텐츠는 아직 없습니다.

AI 입력

패턴에서 "AI 입력"을 고르면 서버로 들어온 프레임을 그대로 보여 줍니다. 서버는 마지막 프레임만 둡니다.

한 프레임은 numpy uint8 배열 (12, 16, 64, 3)을 bytes로 바꾼 것입니다(36,864 bytes). 12는 서브모듈(zone 1–12), 16은 포트(1–16), 64는 위에서부터 LED 순서(구멍 속 1번 LED는 빼고 2번부터), 3은 RGB입니다. 스트립이 없는 포트와 스트립보다 긴 칸은 0으로 둡니다.

보내는 곳은 둘 중 하나입니다. HTTP는 POST /api/sim/frame(본문 = bytes 그대로)이고, WebSocket은 /ws/sim/in(바이너리 메시지 하나가 프레임 하나)입니다. 받는 상태는 GET /api/sim/status 에서 봅니다. 20 fps면 초당 약 0.74 MB입니다.

import numpy as np, urllib.request
f = np.zeros((12, 16, 64, 3), np.uint8)
f[8 - 1, 16 - 1, 0] = (255, 0, 0)   # zone 8 / port 16 = A1, LED 2 빨강
req = urllib.request.Request("/api/sim/frame",
    data=f.tobytes(), method="POST")
urllib.request.urlopen(req)

포트 표는 sim_mapping.csv(배선 proposal, 확정 전)를 따릅니다. 예제 프로그램 : python sim_send.py (zone별 색), python sim_send.py --demo ball. 아두이노로 내보내는 출력은 아직 없습니다.

치수 (고정)
